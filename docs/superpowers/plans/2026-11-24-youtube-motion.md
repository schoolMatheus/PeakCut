# YouTube audience motion Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace simple requests with five YouTube-themed Lottie motions and synchronized quiet effects.

**Architecture:** Author editable Lottie scenes with the supplied reference's Skottie player; distribute transparent WebM assets and the supplied sounds inside `studio/assets/interactions`. **Tech Stack:** Lottie/Skottie (authoring only), Python, ffmpeg, existing bundled fonts.

**Spec:** `docs/superpowers/specs/2026-11-24-youtube-motion-design.md`.
